# Number Guessing Game

A command-line game written in Python. The computer picks a random number
between 1 and 100 and the player has to guess it. After each guess, the
program says whether the secret number is higher or lower, and at the end
it shows how many attempts it took.

## What I practiced

- `while` loops and conditionals
- Functions with parameters and `return`
- Error handling with `try/except`
- The `random` module

## How to run it

1. Make sure Python 3 is installed.
2. Open a terminal in this folder.
3. Run:

```
MINI PROJECT GUESS NUMBER.py
```
